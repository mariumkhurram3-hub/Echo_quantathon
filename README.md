# Echo_quantathon
Entangled Minds: The Quantathon | Qubits Qrew, NED University
Investigator: Marium Khurram
Project Overview
This project investigates ECHO—a claimed quantum experiment alleging faster-than-light (FTL) communication via quantum entanglement. Using Qiskit simulations and error-correction techniques, we analyze whether the results demonstrate actual FTL data transfer or simply standard quantum correlations.
Core Focus Areas
Quantum Circuits: Built and simulated circuits using Qiskit and Qiskit Aer to analyze gates, superposition, and entanglement.
Correlations vs. Signaling: Evaluated whether shared entangled states allow usable information transfer without a classical channel.
Error Correction: Recovered a corrupted binary payload using majority voting algorithms.
Modules Completed
Module 01 — The Gatekeeper: Quantum gates & single-qubit measurement foundations.
Module 03 — The Two Observers: Entanglement dynamics and Bell-state correlations.
Module 05 — The Damaged Message: Binary error correction via majority voting.
Module 04 (Stretch) — The Erased Measurement: Quantum state transformations and erasure sequences.
Main Verdict
Correlated measurement outcomes alone do not constitute a faster-than-light communication channel. While quantum entanglement creates non-local correlations, no usable information can be transmitted faster than light without a supporting classical communication link.
How to Run
Open echo_quantathon_invetsigation.ipynb in Google Colab or Jupyter Notebook.
Run cells sequentially from top to bottom to execute the circuits and simulations.
Review Case_Report.md for detailed mathematical proofs, evidence breakdown, and conclusions.
